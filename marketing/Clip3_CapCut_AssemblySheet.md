## Build steps
1. **VO → A1** at 0:00 (sets length, ~55–60s).
2. **MUSIC → A2**, ~15–20% volume. This one should **build** — pick a track that lifts; align the energy peak to the 0:16 feature montage. Fade out last 1.5s.
3. **V1 montage:** the 0:16–0:40 block is the tricky part — **cut each feature clip to the music beat** (~4s each × 5 = 20s). Use CapCut's beat markers (Audio → Beats) to snap cuts.
4. **Captions (V3):** Auto-captions → English, lower-center, white + black outline.
5. **Headlines (V2):** the cycling feature labels (0:16–0:40) each appear on their matching cut — quick "Pop" in, out before the next.
6. **Split screen (0:00–0:04):** add BIGSHOP and SMALLSHOP as two clips, crop each to half the 9:16 frame side-by-side (or top/bottom).
7. **CTA card (0:52–0:60):** solid bg + LOGO + "XISSuite.com".
8. **Transitions:** hard cuts throughout to keep the montage punchy; no dissolves in the 0:16–0:40 block.

## Polish & export
- **Hook check:** the split-screen contrast + question must read by 0:02.
- **Pace check:** the feature montage should feel fast but legible — each label on screen long enough to read (~1.5s min).
- **Mute test:** labels + captions carry it silent.
- **Loudness:** target −16 LUFS.
- **Export:** 1080×1920, 30fps, MP4/H.264 → `D:\xismarket\marketing\renders\XISSuite_Clip3_Superpowers_v1.mp4`.
